Ufficio

Da qui si caricano i file esportati da Levante e si preparano i file da mandare ai tecnici.

Dati da Levante

  1. Sul PC di Levante lancia Esporta_Levante.bat.
  2. Il .bat crea anche un unico file Esportazione_….zip: tocca Scegli i file di Levante e scegli solo quello. Oppure tocca Leggi l'ultima esportazione (Chrome o Edge sul computer), oppure apri la cartella che si crea (con data e ora) e scegli qui tutti i file (.csv e .json).
  3. Per ogni tecnico vedi cosa è cambiato dall'ultimo invio: manda il file solo a chi ha novità (è un file di testo .txt: il tecnico lo apre dall'app con "Carica i dati" e vede subito cosa è nuovo, spostato o annullato).

La prima volta scegli la cartella export_levante (quella creata accanto a Esporta_Levante.bat): da quel momento l'app ricorda dove cercare e prende da sola l'esportazione più recente.

I file contengono dati dei clienti: mandali solo ai tecnici.

Posta in arrivo

  1. Dalla mail salva gli allegati dei tecnici (PDF e file Dati_…txt).
  2. Tocca il pulsante qui sotto e scegli tutti i file insieme: gli interventi si raggruppano da soli.
  3. Per ogni intervento trovi cosa registrare in Levante (ore, testi da copiare, km, materiali) e il file CSV da caricare con «carica file di testo».
